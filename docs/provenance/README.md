## Current components

* First-party application/parser/analysis/UI sources were developed in this
  workspace from the ACHERON requirements. The first-party code uses the root MIT
  license and cirrune attribution. Shared algorithms are not claimed as exclusive
  intellectual property.
* PE metadata interpretation references the Microsoft PE specification:
  https://learn.microsoft.com/en-us/windows/win32/debug/pe-format
* Machine decoding is performed by the external iced-x86 library. ACHERON's
  adapter/lifter is distinct from that library; its MIT notices remain intact.
* Qt supplies the desktop framework; its library ownership and LGPLv3 notices are
  independent of ACHERON's first-party attribution.
* The supplied test EXEs come from `fixtures/known_source.c`; compiler flags and
  binary hashes are recorded in `fixtures/manifest.json`. They are not extracted
  third-party programs. Synthetic PE fixtures are generated by the tests.
* The small A application icon is code-native geometry in `desktop/theme.py`.
  No outside logo/image asset has been incorporated. Windows system fonts are
  used locally and are not redistributed as first-party font files.

## Recordkeeping for additions

Record each new incorporated component's upstream source, version/hash, purpose,
license, required notices, modifications and redistribution location here and in
THIRD_PARTY.md. Preserve upstream notices verbatim. Separate facts supported by
upstream documentation from inferred implementation behavior.

## Product scope

The repository ships ACHERON Base and ACHERON // CHARON as separate portable
applications. Both share the design system and simplified mode. CHARON integrates
real local models and optional OpenAI Responses. See [AI model provenance](ai-models.md)
for exact source revisions, licenses, runtime hashes and validation scope.
